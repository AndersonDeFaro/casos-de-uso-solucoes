# Apache Hop

Artefatos de ETL desenvolvidos com Apache Hop para leitura, transformação e geração de saídas de dados.

## Estrutura

- `dados/`: arquivos de entrada.
- `pipelines/`: definições de transformações e fluxos de dados.
- `workflow/`: orquestração de pipelines.
- `saida/`: arquivos produzidos pelas execuções.

## Como executar

Abra o projeto no Apache Hop, configure os diretórios de projeto e revise os caminhos de origem e destino. Execute primeiro os pipelines isoladamente e depois os workflows que os orquestram.
