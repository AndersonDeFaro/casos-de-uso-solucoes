# Análises com ETL

Projetos de integração e transformação de dados criados em Apache Hop e Pentaho Data Integration (PDI).

## Ferramentas

- [Apache Hop](ApacheHOP/): pipelines e workflows de processamento de dados.
- [Pentaho PDI](PentahoPDI/): jobs e transformações para processos ETL.

## Como utilizar

Instale a ferramenta correspondente, abra o projeto pela interface gráfica e ajuste os caminhos de arquivos, conexões e permissões conforme o ambiente. Os dados de entrada e as saídas de cada ferramenta permanecem em seus diretórios locais.
