# Formação Data Science

Trilha de estudos em análise de dados, estatística e modelagem preditiva. Os módulos combinam notebooks, exercícios e conjuntos de dados para prática progressiva.

## Módulos

- [Introdução a Data Science](1%20-%20Introducao%20Data%20Science/): exploração de dados de filmes e avaliações.
- [Estatística - Parte 1](2%20-%20Curso%20de%20Estatística/): fundamentos estatísticos e exercícios.
- [Estatística - Parte 2](3%20-%20Cursode%20Estatistica%20Parte%202/): estimativas e continuidade dos conceitos estatísticos.
- [Regressão Linear](4%20-%20Regressao%20Linear/): dados e materiais para estudos de regressão.

## Como executar

Os materiais são notebooks Jupyter. Crie um ambiente Python, instale as bibliotecas requisitadas por cada notebook e execute as células em sequência. Os CSVs distribuídos nas pastas devem permanecer próximos aos notebooks que os consomem.
