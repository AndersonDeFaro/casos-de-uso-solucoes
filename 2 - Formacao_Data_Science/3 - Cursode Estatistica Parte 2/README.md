# Estatística para Data Science - Parte 2

Continuação dos estudos de estatística, com foco em estimativas e exercícios aplicados.

## Arquivos

- `Curso_de_Estatística_Parte_2.ipynb`: notebook principal do módulo.
- `Estimativas.ipynb`: exemplos e atividades sobre estimativas estatísticas.
- `Exercicio Estatistica 2.ipynb`: exercícios práticos.
- `Versão_bibliotecas.ipynb`: conferência das bibliotecas utilizadas.
- `dados.csv`: dados de apoio para os notebooks.

## Como executar

Abra os notebooks em um ambiente Jupyter com as dependências instaladas. Execute as células na sequência proposta e mantenha o arquivo `dados.csv` junto aos notebooks.
