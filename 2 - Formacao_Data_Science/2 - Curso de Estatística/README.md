# Estatística para Data Science - Parte 1

Material introdutório de estatística aplicado a dados, com exercícios e conjuntos de dados de apoio.

## Arquivos

- `Curso_de_Estatística_Parte_1.ipynb`: notebook principal do curso.
- `Exercicio_Estatistica - Data Science.ipynb`: atividades práticas.
- `Verifica_versão.ipynb`: conferência do ambiente e das versões de bibliotecas.
- `dados.csv`: dados utilizados nos exemplos e exercícios.
- `Aula 6 início/`: material complementar da aula.

## Como executar

Prepare um ambiente Jupyter com as bibliotecas importadas no material. Inicie pelo notebook principal e mantenha `dados.csv` no mesmo diretório para que as leituras de arquivo funcionem.
