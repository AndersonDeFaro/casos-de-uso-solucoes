# Regressão Linear

Área reservada para estudos e projetos de regressão linear, organizada entre conjuntos de dados e materiais de implementação.

## Estrutura

- `Dados/`: arquivos de entrada usados nos exercícios e experimentos.
- `Projeto/`: notebooks, scripts e artefatos relacionados ao projeto de regressão.

## Como utilizar

Explore primeiro os arquivos em `Dados/` para entender as variáveis disponíveis. Em seguida, execute os materiais de `Projeto/` com as dependências indicadas nos próprios notebooks ou scripts.

Mantenha caminhos relativos ao mover arquivos, pois os materiais podem referenciar os dados a partir dessa estrutura.
