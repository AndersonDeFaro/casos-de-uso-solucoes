# Introdução a Data Science

Notebook de introdução à análise exploratória de dados usando informações de filmes, créditos e avaliações de usuários.

## Arquivos

- `Introdução a Data Science.ipynb`: notebook principal do módulo.
- `tmdb_5000_movies.csv`: metadados de filmes do TMDB.
- `tmdb_5000_credits.csv`: informações de elenco e equipe dos filmes.
- `ml-latest-small/`: dados do MovieLens, incluindo filmes, avaliações, tags e links externos.

## Como executar

Instale Jupyter, Pandas e as demais bibliotecas importadas pelo notebook. Execute `Introdução a Data Science.ipynb` a partir desta pasta para preservar os caminhos relativos dos arquivos CSV.

## Fontes dos dados

Os dados de avaliações são fornecidos pelo MovieLens. Consulte `ml-latest-small/README.txt` para condições de uso e citação do conjunto de dados.
