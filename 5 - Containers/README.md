# Containers

Exemplos de conteinerização com Docker e Docker Compose, incluindo imagens simples, aplicações com múltiplos serviços e projetos de referência.

## Conteúdo

- [Docker](docker/): exemplo de construção de imagem a partir de Dockerfile.
- [Docker Compose](docker-compose/): ambientes compostos, como Airflow, FastAPI, Oracle, PostgreSQL e outros exemplos de estudo.

## Pré-requisitos

Instale Docker Desktop ou Docker Engine com Docker Compose. Cada projeto pode exigir variáveis de ambiente, imagens adicionais e portas disponíveis na máquina.

Antes de iniciar qualquer composição, consulte o README local e revise volumes, portas e credenciais configuradas.
