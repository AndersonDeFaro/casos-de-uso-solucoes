# Análises de Criptomoedas

Notebooks para coleta e exploração de dados de criptoativos.

## Arquivos

- `1-0_Coletar_Dados_Cripto.ipynb`: coleta e preparação inicial dos dados.
- `1-1_Coletar_Dados_Cripto_Previsão_Simples.ipynb`: extensão do estudo com uma previsão simples.

## Como executar

Instale Jupyter e as bibliotecas importadas. Revise as fontes e os parâmetros de consulta antes de executar, pois cotações e APIs de mercado mudam continuamente e não constituem recomendação financeira.
