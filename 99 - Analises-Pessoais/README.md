# Análises Pessoais

Coleção de explorações independentes sobre criptoativos, leilões e mercado financeiro, apoiadas por notebooks Python e arquivos CSV.

## Conteúdo

- [Criptomoedas](cripto_moedas/): coleta de dados e previsão simples de criptoativos.
- [Leilões](leiloes/): coleta de dados de leilões.
- [Mercado Financeiro](mercado_financeiro/): consumo de APIs, dados de empresas, tickers e análises financeiras.
- `dados/`: arquivos CSV consolidados e estatísticas de ações negociadas na B3.

## Como executar

Crie um ambiente Python isolado e instale as bibliotecas usadas pelo notebook escolhido. Exemplos que consultam APIs ou páginas externas podem exigir credenciais, conexão ativa e adaptação a mudanças nas fontes de dados.
