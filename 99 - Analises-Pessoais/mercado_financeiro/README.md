# Análises de Mercado Financeiro

Notebooks para coleta, atualização e análise de dados de empresas e ativos financeiros.

## Arquivos

- `1_0_ConsumirAPI.ipynb`: consumo de dados por API.
- `1_1_AtualizarSymbol.ipynb`: atualização de símbolos de ativos.
- `1_2_ObterDadosEmpresas.ipynb`: coleta de dados de empresas.
- `2_0_Obter_Tickets.ipynb`: obtenção de tickers.
- `2_1_Analizar_Dados_Empreas.ipynb`: análise dos dados coletados.
- `2_2_Exportar_Dados_GDrive.ipynb`: exportação de resultados para Google Drive.

## Segurança e execução

Configure credenciais e tokens por variáveis de ambiente ou pelos mecanismos seguros do ambiente Jupyter. O arquivo `client_secrets.json` contém configuração sensível e não deve ser compartilhado ou versionado com credenciais reais.

Os notebooks são materiais de estudo e análise de dados, não recomendação de investimento.
