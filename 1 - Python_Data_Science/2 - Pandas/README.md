# Estudos com Pandas

Exercícios e exemplos de manipulação de dados tabulares com a biblioteca Pandas.

## Arquivos

- `Python_para_Data_Science_Pandas.ipynb`: introdução à criação, seleção, transformação e análise de DataFrames.
- `Pandas IO.ipynb`: operações de entrada e saída de dados.
- `data/`: arquivos de apoio para leitura nos notebooks.

## Como executar

Instale Jupyter, Pandas e as bibliotecas importadas nas células. Abra o notebook escolhido e execute-o sequencialmente para preservar o contexto das variáveis e dos dados carregados.
