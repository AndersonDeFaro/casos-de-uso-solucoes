# Estudos com NumPy

Notebooks introdutórios para trabalhar com arrays e fundamentos de análise de dados em Python com NumPy.

## Arquivos

- `Python_Data_Science_Numpy.ipynb`: conceitos e operações principais com NumPy.
- `logica de programacao.ipynb`: exercícios de lógica aplicados ao contexto dos estudos.
- `Atividade dados nulos.ipynb`: identificação e tratamento de valores ausentes.
- `EDA-Gorjetas.ipynb`: análise exploratória do conjunto de dados de gorjetas.
- `data/`: arquivos de suporte utilizados pelos notebooks.

## Como executar

Instale Jupyter, NumPy e as demais bibliotecas importadas nos notebooks. Em seguida, abra o material desejado e execute as células na ordem apresentada.
