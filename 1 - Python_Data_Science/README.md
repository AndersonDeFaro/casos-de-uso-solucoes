# Python Data Science

Trilha de estudos práticos em Python para manipulação, análise, visualização e modelagem de dados. Os módulos são compostos principalmente por Jupyter Notebooks e arquivos de apoio.

## Módulos

- [NumPy](1%20-%20Numpy/): fundamentos de arrays, lógica de programação, tratamento de nulos e análise de gorjetas.
- [Pandas](2%20-%20Pandas/): leitura, transformação e análise de dados tabulares.
- [Visualização](3%20-%20Pyhton%20Visualization/): análise de séries temporais e visualizações com dados de gorjetas.
- [NLP](4%20-%20NLP/): construção de um corretor ortográfico com técnicas de texto.
- [Web Scraping](5%20-%20Web%20Scraping/): extração e tratamento de dados de páginas web.
- [TensorFlow](6%20-%20TensorFlow/): introdução ao uso da biblioteca para aprendizado de máquina.

## Como executar

1. Crie um ambiente virtual Python.
2. Instale Jupyter e as bibliotecas importadas pelo notebook escolhido.
3. Abra o notebook no VS Code ou Jupyter e execute as células em sequência.

Arquivos nas pastas `data`, `web` e `output` são insumos ou resultados de apoio aos exercícios.
