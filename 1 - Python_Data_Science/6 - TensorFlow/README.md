# Introdução ao TensorFlow

Notebook inicial para exploração da biblioteca TensorFlow em projetos de aprendizado de máquina.

## Arquivo

- `1_0_Introducao.ipynb`: introdução aos conceitos e à configuração inicial do TensorFlow.

## Como executar

Crie um ambiente virtual compatível com a versão do Python e instale TensorFlow e Jupyter. Abra o notebook e execute as células sequencialmente; alguns recursos podem exigir suporte específico de hardware ou do ambiente de execução.
