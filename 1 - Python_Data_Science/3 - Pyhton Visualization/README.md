# Visualização de Dados e Séries Temporais

Material de estudo para análise e visualização de séries temporais com dados de gorjetas.

## Arquivos

- `Time Series.ipynb`: notebook com análises de séries temporais e visualizações.
- `tips.csv`: conjunto de dados original de gorjetas.
- `tips_atualizado.csv`: versão ajustada do conjunto de dados.
- `material curso - Time Series/`: materiais complementares do curso.

## Como executar

Abra `Time Series.ipynb` em um ambiente Jupyter com as bibliotecas importadas no notebook instaladas. Mantenha os arquivos CSV no diretório atual para que os caminhos de leitura funcionem conforme o material.
