# Web Scraping

Exemplos de coleta e preparação de dados extraídos de páginas web com Python.

## Arquivos

- `Web Scraping.ipynb`: notebook principal com as etapas de extração e tratamento.
- `Exercicios Motors.ipynb`: exercícios de coleta de informações relacionadas a veículos.
- `web/`: páginas ou recursos locais usados nos exemplos.
- `output/`: resultados gerados durante os exercícios.

## Como executar

Instale Jupyter e as dependências importadas no notebook. Ao executar exemplos que consultam páginas externas, verifique os termos de uso do site, a disponibilidade do endpoint e eventuais limites de acesso.
