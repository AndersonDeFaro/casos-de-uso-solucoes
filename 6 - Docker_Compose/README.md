### Comandos básicos

#### Subir docker compose em segundo plano
docker compose up -d 

#### Parar docker compose
docker compose down

#### Parar docker compose apagando volumes
docker compose down -v

#### Verificar composes que estão rodando
docker compose ps

#### Acompanhar Logs
docker compose logs -f
