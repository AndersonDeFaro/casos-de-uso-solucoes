# Bancos de Dados

Estudos e exemplos práticos de plataformas de dados, abrangendo processamento distribuído com Databricks e consultas em MongoDB.

## Conteúdo

- [Databricks](1%20-%20Databricks/): notebooks sobre formatos de arquivos, Spark, Scala, Delta Lake e projetos de análise.
- [MongoDB](2%20-%20MongoDB/): notebooks de visualização e exploração da base de exemplo MFlix.

## Como utilizar

Os materiais do Databricks devem ser importados ou executados em um workspace compatível. Os notebooks de MongoDB exigem uma instância acessível com as coleções de exemplo carregadas.
