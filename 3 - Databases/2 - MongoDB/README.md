# Estudos com MongoDB

Notebooks de exploração e visualização de documentos da base de exemplo MFlix no MongoDB.

## Arquivos

- `visualizar_mflix-basico.ipynb`: consultas e visualizações iniciais da base MFlix.
- `visualizar_mflix.ipynb`: exploração complementar da coleção e dos dados de filmes.

## Como executar

1. Disponibilize uma instância MongoDB com a base de exemplo MFlix.
2. Configure a string de conexão no notebook, sem incluir credenciais no código versionado.
3. Instale Jupyter, PyMongo e as bibliotecas de análise importadas pelo material.
4. Execute as células em sequência.
